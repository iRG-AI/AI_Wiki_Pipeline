## 규칙
1. README 📝 절 = 요약 이력 표(3칸: `| **[vX.Y.Z](docs/changelog/YYYY-MM.md#vX-Y-Z)** | YYYY-MM-DD | **제목** |`, 버전 내림차순, 제목 100자 안팎) + 이 폴더 링크 목록. 상세 본문은 README 에 쓰지 않는다.
2. 한 달 한 파일(항목 1개여도 합치지 않는다). 새 항목은 맨 위. 헤딩 바로 윗줄에 `<a id="vX-Y-Z"></a>` (`.` → `-`, 접미사 `v4.6.0-a` → `v4-6-0-a`, 같은 버전이 둘이면 뒤 날짜에 `-2`).
3. 표 칸 안 `|` 는 `\|`(코드 스팬 안도). 상세가 없는 행은 링크를 만들지 않는다 — 깨진 링크 0.
4. 번호: 단일 줄 · HEAD 기준(`git log --oneline -1`) · push 한 번호는 고쳐 쓰지 않는다(옮길 때는 해시 · 원 번호를 각주로).
5. MAJOR, 또는 소스·저장소·실행 경로·예약 작업을 더하거나 빼거나 바꾸는 MINOR 는 같은 커밋에서 README 본문도 맞춘다.
6. 문서·테스트만 바꾼 커밋도 PATCH 를 올린다(v4.19.1~). `-a`·`-b` 는 새로 만들지 않는다.
7. 공개 저장소 — 개인 절대경로·맥 이름·이메일·`.env` 값을 쓰지 않는다.
8. 감지: `scripts/test_readme_changelog.py` (v4.19.2~, `scripts/run_all_tests.sh` 에 포함).

> v4.4: 카톡 꿀팁의 추정 제목(「제목 미확인」·URL 조각)을 원문 제목으로 고치는 `scripts/retitle_tips.py` 를 넣었습니다 — 장부·Obsidian 노트(파일명 포함)·링크를 함께 바꿉니다.
> v4.5: Wiki 합성 결과(엔티티·개념)를 장부 `wiki_extract` 에 쌓고 `_wiki` 페이지를 매번 전체로 다시 그립니다.
> v4.6-a: 신규 영상은 **실제 영상**(YouTube URL)을 Gemini 에 넣어 요약하고, 판매가 주목적·일반론·AI 무관 영상은 등급 `exclude` 로 표시해 Wiki 합성·검색에서만 뺍니다(노트는 그대로). 영상 입력이 안 되면 예전처럼 설명란으로 요약합니다.

> v4.7: Wiki 검색 화면을 개편했습니다 — 처음 열면 전체 목록이 나오고, 토픽 여러 개·종류·날짜·조회수·채널 등으로 거르고, 머리줄을 눌러 정렬합니다. 비슷한 영상·노트 전체 보기·엑셀 내려받기도 됩니다(회사 디자인 시스템 DS 1.1.23).
