### 환경 변수 — 이름 표로 (값 금지)

지금 `.env` 예시 코드 블록을 아래 꼴의 표로 바꾼다. 블록 안의 모든 변수를 빠짐없이 옮긴다.

| 변수 | 필수 | 설명 |
|---|---|---|
| `YOUTUBE_API_KEY` | ✅ | YouTube Data API v3 읽기 키 |
| … | | |

- **값 칸이 없다.** 예시 값(`~/Downloads`, 사설 대역 예시, `false`, 숫자)도 쓰지 않는다. 대신 설명에 의미를 쓴다 — 예: `WIKI_LAN_ALLOW_CIDR` → 「집 안 사설 대역(/16~/32, 쉼표로 여러 개). 없거나 틀리면 127.0.0.1 전용」, `VIDEO_MAX_SECONDS` → 「영상 입력 길이 상한(초). 없으면 코드 기본값」.
- 코드 기본값의 숫자는 설명에 「코드 기본값 N」으로 남겨도 된다(값이 아니라 코드 상수). 운영 중인 실제 값(예: 재요약 운영값)은 쓰지 않는다 — `[CC-1104-D]` 가 붙인 「(코드 기본값 — 운영은 실행당 20·하루 40)」 주석 두 줄은 이 표로 바꾸면서 사라진다.
- 블록 안의 그룹 주석(「(v4.6) 실제 영상 요약 — …」 등)은 표 위 소제목이나 설명 칸으로 살린다. 「선택」 변수는 필수 칸 비움.

### 버전 머리 형식

- 상세 로그 `#### [vX.Y] — YYYY-MM-DD (제목)` → `#### [vX.Y.0] - YYYY-MM-DD (제목)`. 이미 X.Y.Z 면(`v3.2.1`·`v2.7.1`) 그대로 `#### [v3.2.1] - …`. `v4.6-a`·`v4.6-b` → `[v4.6.0-a]`·`[v4.6.0-b]`.
- 대시는 ` — `(긴 대시) → ` - `(하이픈) 머리 줄에서만. 본문은 그대로.
- 제목 괄호가 없는 머리(`v2.4`·`v1.2`·`v1.1`·`v1.0` 등)는 그 버전 불릿을 보고 이모지 한 줄 제목을 붙인다(괄호 안, 20자 안팎).
- 요약 표의 버전 칸도 같은 꼴(`v4.19.0`·`v4.6.0-b`·`v3.2.1`)로. 표의 다른 칸은 그대로.
- 머리 개수는 0-3 의 37 그대로.
